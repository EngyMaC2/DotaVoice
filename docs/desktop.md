# Настольное приложение DotaVoice

Это руководство для тех, кто просто хочет пользоваться программой. Установка,
первый запуск, голосовая связь и оверлей — по шагам.

## Установка

### Windows: обычная программа

Самый простой путь:

1. Запустите `install.bat`. Он поставит приложение и положит ярлык **DotaVoice**
   на рабочий стол и в меню «Пуск».
2. Запускайте приложение двойным кликом по ярлыку.

Если хочется, чтобы всё выглядело как у обычных программ — отдельный
`DotaVoice.exe` и установщик `DotaVoice-<версия>.msi` (Windows Installer),
запустите:

```bat
build_windows.bat
```

Готовые файлы появятся в папке `dist`:

| Файл | Что это |
|---|---|
| `DotaVoice.exe` | само приложение, один файл, запускается двойным кликом |
| `DotaVoice-0.2.0.msi` | установщик: ярлыки на рабочем столе и в «Пуск», запись в «Программы и компоненты» |

Установщик `.msi` делает всё как принято в Windows: выбор папки, ярлыки,
корректное удаление через «Программы и компоненты». Для его сборки нужен
[WiX Toolset v3](https://github.com/wixtoolset/wix3/releases); если его нет,
`.exe` всё равно собирается и работает сам по себе.

### Linux и macOS

```bash
./install.sh          # Linux / macOS
```

Установщик создаёт отдельное виртуальное окружение, ставит зависимости и
добавляет ярлык запуска на рабочем столе и в меню приложений.

Настройки и логи хранятся не рядом с кодом, а в стандартных пользовательских
каталогах:

| Система | Настройки | Логи и данные |
|---|---|---|
| Windows | `%APPDATA%\DotaVoice` | `%LOCALAPPDATA%\DotaVoice` |
| macOS | `~/Library/Application Support/DotaVoice` | то же |
| Linux | `~/.config/dotavoice` | `~/.local/share/dotavoice` |

## Первый запуск: мастер настройки

Запустите `dotavoice-gui` (или ярлык «DotaVoice»). Откроется мастер из трёх шагов.

### Шаг 1. Steam и Dota 2

Приложение само ищет Steam и библиотеку с Dota 2 (реестр Windows, типовые пути,
`libraryfolders.vdf`) и показывает найденные профили Steam из `loginusers.vdf`.
Выберите профиль или укажите папку Dota 2 вручную.

На этом шаге приложение **само создаёт файл интеграции**
`gamestate_integration_dotavoice.cfg` в каталоге

```
<Dota 2>/game/dota/cfg/gamestate_integration/
```

Токен из этого файла должен совпадать с токеном в настройках приложения. Мастер
подставляет его сам; менять ничего не нужно.

Здесь же есть галочка «Создать ярлык на рабочем столе» — по умолчанию включена.

### Шаг 2. Голос

- **Имя в матче** — как вас видят другие участники.
- **Микрофон** и **устройство вывода** — можно оставить системные по умолчанию.
- **Push-to-talk** — включить передачу по клавише (по умолчанию `V`).

### Шаг 3. Оверлей

- **Включить оверлей** — показывать список участников поверх игры.
- **Положение** — один из четырёх углов экрана.
- **Прозрачность** — насколько плотный фон под списком.

Нажмите «Готово». Мастер сохранит настройки и запустит движок.

## Как это работает в матче

1. Начинается матч — Dota 2 отправляет состояние на локальный адрес приложения.
2. Приложение находит матч по `match_id` и создаёт (или подхватывает) сессию.
3. Оно **само подключается** к голосовой комнате этого матча.
4. Игроки распределяются по двум каналам: **Силы Света** и **Силы Тьмы**.
5. Каналы изолированы: свет не слышит тьму и наоборот.
6. Оверлей показывает, кто говорит, кто в муте и за какую сторону играет.

Перезапуск игры или кратковременный обрыв связи сессию не разрывают: как только
игра снова пришлёт тот же `match_id`, приложение вернётся в ту же комнату.

## Главное окно

- **Матчи** — список активных матчей. Внутри видно оба канала и игроков в них.
- **Индикатор говорящего** — подсвечивается у того, кто сейчас говорит.
- **Заглушить** — мут на стороне сервера: заглушённое аудио не пересылается
  другим участникам.
- **Сменить команду** — вручную перевести игрока в другой канал (нужно редко,
  обычно команды приходят из игры).
- **Push-to-talk** — удерживайте кнопку (или клавишу `V`), чтобы говорить.
- **Оверлей** — включить или выключить показ поверх игры.
- **Настройки** — папки Steam/Dota 2, установка файла интеграции, устройства
  звука, голосовой бэкенд, положение оверлея.

## Оверлей

Оверлей — это отдельное прозрачное окно поверх игры. Оно:

- не перекрывает картинку — фон полностью прозрачный;
- не ловит клики и нажатия — мышь и клавиатура работают как обычно;
- обновляется мгновенно по событиям из движка.

Если вы стримите, тот же оверлей можно добавить в OBS как **Browser Source**:

```
http://localhost:12000/overlay
```

## Голосовой бэкенд

По умолчанию используется **встроенный голосовой сервер** (`relay`). Он работает
на том же порту, что и приложение, и не требует ничего настраивать.

Если нужно, чтобы все игроки подключались к одному общему узлу, укажите адрес
внешнего сервера в поле «Адрес голосового сервера» (например,
`udp://192.168.1.10:12000`). Протокол тот же.

Есть также бэкенды `memory` (только состояние, без звука — удобно для проверки)
и `discord` (каналы и мут через Discord).

## Частые вопросы

**Игра не появляется в окне.** Проверьте, что файл интеграции создан (кнопка
«Установить файл интеграции» в настройках) и что токен совпадает. Перезапустите
Dota 2 — файлы интеграции читаются при старте игры.

**Меня не слышат.** Проверьте, что выбран правильный микрофон, и что передача
включена (кнопка push-to-talk). Если используется бэкенд `memory`, звук не
передаётся по определению — выберите `relay`.

**Оверлей не виден.** Убедитесь, что он включён в окне и что игра запущена не в
эксклюзивном полноэкранном режиме (используйте «оконный без рамки»).

**Хочу запустить без интерфейса.** Используйте сервисный режим:
`python -m dota_voice`. Он поднимает тот же движок и панель управления по адресу
`http://localhost:12000/`.
